# docs/reference

Reference notes: explanations recorded from design discussions that are neither a work order nor a
design-of-record — an option weighed against the platform as it stands, with what would have to be
built named. Dated, Authority-marked, and linked to the design notes they lean on. When one turns
into work, it gets a work order; the note stays as the reasoning trail.

- [`twin-from-topology-diagram.md`](twin-from-topology-diagram.md) — building a twin from a network
  topology diagram with what exists and what is being built; why the input contract is a logical
  diagram, not a physical one (2026-09-08).
- [`ui-consolidation/`](ui-consolidation/) — the Unified Console research and ruling (2026-09-29):
  a backend audit, a UI surface inventory, a UI history/decisions report, the design ruling that
  turned into `docs/design/16-unified-console.md`, the API contract as built, and the deletion
  candidates list pending the user's approval.
